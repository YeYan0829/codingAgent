# 历史文档

本目录保存已经完成、被取代或仅用于阶段性论证的设计、调研、评测和版本资料。它们用于追溯“为什么
曾经这样设计”，不代表当前接口、状态或实施顺序。

- `design/`：已完成或被后续实现取代的 Technical Design；
- `research/`：Context 等阶段性源码与方案调研；
- `evaluation/`：历史真实模型任务审计；
- 其余文件：早期版本路线、能力盘点和产品设计快照。

当前入口见 [`../PROJECT_GUIDE.md`](../PROJECT_GUIDE.md)，当前实现见
[`../ARCHITECTURE.md`](../ARCHITECTURE.md)，当前 benchmark 见
[`../BENCHMARKING.md`](../BENCHMARKING.md)。历史内容与当前文档冲突时，以代码、测试和当前文档为准。
