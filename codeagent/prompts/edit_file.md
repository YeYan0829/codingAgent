用 old_text/new_text 提供连续的替换片段。old_text 必须对应文件中的原文，包括空白、注释和文档字符串，并包含足够上下文以唯一定位。保持片段简短，只包含修改行及必要上下文；不要夹入长段不变代码。new_text 为空表示删除该片段；移动代码可在原处删除、在目标处插入。通过path和edits=[{old_text,new_text}, ...]传参。多处修改按顺序准备，准备失败整组不写入；提交失败尝试恢复涉及文件，无法确认时保留现场。仅支持UTF-8普通文件，每文件最多512000字节、每批最多50项；修改直接生效，受控编辑可由用户通过CLI undo撤销。已有内容足够时可直接编辑，不要求额外读取操作。
